# 前言

> 本章帮助你判断这本书是否适合你，以及怎样阅读最有效。

## 本书写给谁

- **算法工程师**：想把模型训练/推理跑得更快，部署到 GPU/NPU。
- **软件工程师**：需要理解异构系统的编程模型，写出能用上加速器的代码。
- **产品经理**：要做技术选型与成本/收益判断（关注 📋 小节即可）。

## 你不需要的预备知识

不需要硬件微架构细节。只要会一门系统语言（C/C++ 或 Python），并了解基本程序运行模型即可。

## 本书主线：CPU + GPU + NPU 协同模型

CPU 负责控制流、数据准备、任务调度和结果收口；GPU 负责通用并行计算与性能优化；NPU 负责固定模型的推理和能效部署。理解“谁算什么、数据在哪、何时同步”，就抓住了主线。

OpenCL/SYCL 只作为跨平台补充，FPGA 只在选型章节作为特殊场景对照。本教程的核心是把 CPU、GPU、NPU 组织成可交付系统。

## 如何使用本书

先看 [教程架构](ARCHITECTURE.md) 确认章节职责，再看 [使用说明](USAGE.md) 选择阅读路径。分层标记：

- **⚡️入门必读** — 第一次接触可只读这些。
- **🔬进阶探索** — 想深入的读者再看。
- **📋产品经理视角** — 选型与决策。

## 配套代码与运行环境

代码在 `examples/`，每章独立可运行。共享工具在 `examples/common/`。环境搭建见[附录A](appendix/A-environment-setup.md)，CPU 示例最低只需 Linux + GCC。
