# 前言

> 本章帮助你判断这本书是否适合你，以及怎样阅读最有效。

## 本书写给谁

- **算法工程师**：想把模型训练/推理跑得更快，部署到 GPU/NPU。
- **软件工程师**：需要理解异构系统的编程模型，写出能用上加速器的代码。
- **产品经理**：要做技术选型与成本/收益判断（关注 📋 小节即可）。

## 你不需要的预备知识

不需要硬件微架构细节。只要会一门系统语言（C/C++ 或 Python），并了解基本程序运行模型即可。

## 本书主线：Host + Device 协同模型

Host（通常是 CPU）负责控制流和数据准备，Device（GPU/NPU）负责大规模并行计算。理解“谁算什么、数据在哪、何时同步”，就抓住了主线。

一句话总结：这不是单一 CUDA 或 OpenCL 编程手册，而是一门讲解如何把 CPU、GPU、NPU 等异构能力组织成可交付系统的实践教程。

## 如何使用本书

先看 [使用说明](USAGE.md)，再看根目录 [README 的阅读路径图](../README.md#阅读路径图)。分层标记：

- **🔬进阶探索** — 想深入的读者再看。
- **📋产品经理视角** — 选型与决策。

代码在 `examples/`，每章独立可运行。共享工具在 `examples/common/`。环境搭建见[附录A](appendix/A-environment-setup.md)，CPU 示例最低只需 Linux + GCC。
