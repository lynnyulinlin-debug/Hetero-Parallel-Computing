# 附录

| [A. 按学习任务选择环境](A-environment-setup.md) | 选择 CPU、CUDA、Jetson 或 NPU 环境 | 开始运行示例前 |
| [B. 延伸阅读与资源](B-further-reading.md) | 查阅标准、论文和厂商资料 | 完成当前章节后 |
