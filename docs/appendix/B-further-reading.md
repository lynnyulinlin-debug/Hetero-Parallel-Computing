# 附录B 推荐的延伸阅读与资源

> 这里列的是适合继续深挖的入门级和工程级资料，按“书籍 → 论文 → 官方文档”排序。

## 书籍

- 必读：
  - *Programming Massively Parallel Processors*（David B. Kirk, Wen-mei W. Hwu）
  - *CUDA by Example*（Jason Sanders, Edward Kandrot）
  - *Systems Performance*（Brendan Gregg）

## 论文

- 必读：
  - Roofline model：Samuel Williams 等人的原始 Roofline 论文
  - *In-Datacenter Performance Analysis of a Tensor Processing Unit*（Google TPU 相关论文）
  - 量化相关综述或 PTQ/QAT 经典论文，用于理解部署前后的精度损失
- 选读：
  - 面向内存层次、带宽和算术强度分析的系统性能论文

## 开源项目与官方文档

- 必读：
  - NVIDIA CUDA Programming Guide 与 CUDA Samples
  - Nsight Systems / Nsight Compute 官方文档
  - ONNX 官方文档
  - 各 NPU 厂商 SDK 文档与 sample 工程（RKNN、CANN、TFLite delegate 等）
- 选读：
  - OpenCL 规范与 Khronos 官方资源
  - SYCL / oneAPI 官方文档
