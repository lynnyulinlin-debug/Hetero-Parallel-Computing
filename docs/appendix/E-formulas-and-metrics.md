# 附录 E：公式与指标表

> 本表用于写实验记录和解释测量结果，不用于从单次运行推导通用性能结论。公式中的时间必须采用同一输入、同一统计口径和同一环境；符号含义以本表为准。

## 并行收益

| 名称 | 公式 | 变量与单位 | 使用边界 |
|---|---|---|---|
| 加速比 | `S = T_serial / T_parallel` | `T`：同一工作负载的耗时，单位可为 ms 或 s | 两个实现必须完成相同工作并通过正确性校验；不能跨机器直接比较。 |
| 并行效率 | `E = S / p` | `p`：参与线程或处理器数量，无量纲 | `p` 不等于物理核心数时，应记录实际线程配置；效率低不自动说明实现错误。 |
| Amdahl 上限 | `S_max = 1 / (f_s + (1 - f_s) / p)` | `f_s`：串行比例；`p`：并行资源数量 | 固定问题规模的理想上限；不含同步、搬运和负载不均。 |
| Gustafson 缩放 | `S_G = p - f_s (p - 1)` | `f_s`：在 `p` 个资源上的串行时间比例 | 适合讨论规模随资源增长的场景，不替代固定规模测量。 |

## 算子与 Roofline

| 名称 | 公式 | 变量与单位 | 使用边界 |
|---|---|---|---|
| 算术强度 | `AI = FLOPs / Bytes_moved` | `FLOPs`：浮点运算次数；`Bytes_moved`：各层级实际搬运字节数 | 必须说明统计的是理论最少搬运、DRAM 搬运还是总线搬运。 |
| Roofline 上界 | `P <= min(P_peak, AI x BW_peak)` | `P`：性能；`P_peak`：峰值算力；`BW_peak`：峰值带宽 | 是上界模型；真实有效带宽与有效峰值往往更低。 |
| 有效带宽 | `BW_effective = Bytes_moved / T` | 单位常为 GB/s；`T` 为测量时间 | 只适合已明确数据移动量的操作；不要把缓存命中后的结果当作 DRAM 带宽。 |
| FLOP/s | `Performance = FLOPs / T` | 单位常为 GFLOP/s 或 TFLOP/s | 运算计数规则必须明确，例如一次 FMA 通常计为 2 FLOPs。 |

## 服务与流水线

| 名称 | 公式 | 变量与单位 | 使用边界 |
|---|---|---|---|
| 吞吐 | `Throughput = N_completed / T_window` | `N_completed`：窗口内完成量；`T_window`：窗口时长 | 应明确单位，例如 frame/s、sample/s、token/s；预热阶段不应混入统计窗口。 |
| 端到端延迟 | `L_e2e = L_queue + L_prepare + L_transfer + L_compute + L_postprocess` | 各项为同一请求路径上的耗时 | 只在阶段边界和时间戳一致时可相加；异步重叠不能简单把所有阶段均值相加。 |
| Little 定律 | `L = lambda W` | `L`：系统内平均工作项数；`lambda`：平均到达率；`W`：平均停留时间 | 仅适用于稳定状态的长期平均；不适合解释短暂突发或有丢帧策略的单次样本。 |
| 排队长度上界 | `Q_max = max(Q(t))` | `Q(t)`：时刻 `t` 的队列长度 | 用于观察背压；不能单独代表端到端延迟或吞吐。 |
| P95 延迟 | `P95 = percentile(L_i, 95)` | `L_i`：每次请求延迟样本 | 样本量、预热规则和采样窗口必须记录；P95 不等于最大延迟。 |

## 模型量化与正确性

| 名称 | 公式 | 变量与单位 | 使用边界 |
|---|---|---|---|
| 仿射量化 | `q = clamp(round(x / s) + z, q_min, q_max)` | `x`：浮点值；`s`：scale；`z`：zero point | 实际量化方案可能是 per-tensor、per-channel 或对称量化，应记录具体工具链。 |
| 反量化 | `x_hat = s(q - z)` | `x_hat`：近似恢复值 | 反量化不能恢复截断和舍入造成的全部信息。 |
| 最大绝对误差 | `max_abs = max_i abs(a_i - b_i)` | `a_i`：参考结果；`b_i`：候选结果 | 需要配合输入范围解释；单独不足以判断相对精度。 |
| 最大相对误差 | `max_rel = max_i abs(a_i - b_i) / max(abs(a_i), epsilon)` | `epsilon`：避免除零的小正数 | 接近零的参考值会放大相对误差，必须同时报告绝对误差。 |

## 记录模板

在实验记录中至少写清：

```text
输入：规模、数据来源、模型或帧率
实现：参考实现与候选实现、关键修改
环境：硬件、编译器/运行时版本、线程或 batch 配置
口径：warmup、样本数、统计量、是否包含传输与排队
结果：正确性、耗时/吞吐/分位数、执行模式（simulated 或 real）
边界：本次结果不能推广到哪些输入、设备或部署条件
```
