# 11.4 量化原理

量化的本质，是把高精度浮点数映射到更低精度表示，以换取更低存储和更高执行效率。NPU 部署里，量化不是可选项，而是大多数场景的前置条件。

## 11.4.1 PTQ 与 QAT

- **PTQ（Post-Training Quantization）**：不重新训练，靠校准集估计量化参数。
- **QAT（Quantization-Aware Training）**：训练时模拟量化误差，精度通常更稳。

工程上，PTQ 更适合先跑通流程；QAT 更适合最终精度敏感、且有训练条件的项目。

## 11.4.2 校准集为什么重要

校准集不是“随便拿几张图就行”，而是要尽可能代表真实数据分布。

- 分类任务里，校准集要覆盖主要类别和光照变化。
- 检测任务里，校准集还要覆盖尺度、背景、目标密度和遮挡情况。
- 如果校准集偏得很厉害，量化后精度下降会非常明显。

## 11.4.3 分类和检测的量化差异

分类模型通常更容易量化，因为后处理相对简单；检测模型更容易暴露问题，因为它还带着 NMS、阈值过滤、框坐标还原这些后处理逻辑。

所以：

- **分类模型** 更适合当第一个部署样例。
- **检测模型** 更适合展示真实工程的复杂度。
