# 第8章 异构协处理器概述

> 本章先建立“主-从内存模型”和“该不该上加速器”的判断框架。

第8章是第三篇的入口，先把后续章节都会反复用到的三个问题放在最前面：

1. 数据为什么必须在 Host 和 Device 之间搬运。
2. GPU 和 NPU 为什么不是同一种协处理器。
3. 到底该不该把一个问题放到加速器上做。

本章分成三个部分：

1. [8.1 主-从内存模型：Host ↔ Device](08-1-host-device-memory-model.md)
2. [8.2 协处理器的分类](08-2-accelerator-types.md)
3. [8.3-8.4 性能指标与计算密度判断](08-3-metrics-and-roofline.md)

## 先看什么

- 先看 [8.1](08-1-host-device-memory-model.md)，再看 [8.2](08-2-accelerator-types.md)，最后看 [8.3-8.4](08-3-metrics-and-roofline.md)。

## 本章要点

1. Host/Device 各自独立内存，数据搬运是核心复杂性。
2. GPU 通用、NPU 专用，设计哲学不同。
3. 📋 用算术强度判断是否值得上加速器，别被"峰值算力"误导。
4. 第8章的作用不是展示性能，而是先建立“是否值得上加速器”的判断门槛。
