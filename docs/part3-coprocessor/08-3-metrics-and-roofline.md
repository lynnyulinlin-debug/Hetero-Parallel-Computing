# 8.3-8.4 性能指标与计算密度判断

## 8.3 关键性能指标

- 峰值算力（FLOPS/TOPS）、内存带宽（GB/s）、延迟、功耗（TDP）。
- **算术强度（arithmetic intensity）= 计算量 / 数据传输量**，决定受限于算力还是带宽（Roofline 模型雏形）。

## 8.4 📋 产品经理视角：如何估算计算密度决定是否上加速器

- 计算密度低（如向量加法）→ 带宽受限，加速器收益有限。
- 计算密度高（如矩阵乘、卷积）→ 算力受限，加速器威力尽显。
