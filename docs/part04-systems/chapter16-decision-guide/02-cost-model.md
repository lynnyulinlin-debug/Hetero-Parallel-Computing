# 16.2 开发成本估算

这一节讨论的是“选了之后要付出什么”，因为很多路线在纸面上可行，落到团队里就会被成本打穿。

- 人员技能、工具链成熟度、迭代周期决定开发成本。
- 隐性成本主要在模型转换调试、算子适配和版本维护。

### 16.2.1 成本到底花在哪

很多团队在前期只算“硬件买多少钱”，但真正的成本通常分布在下面这些地方：

- 模型导出和转换
- 算子适配与替换
- 校准集准备
- 板端调试
- 版本兼容维护
- 回归测试和性能复测

如果团队没有现成经验，这些成本往往比硬件采购更难估，也更容易拖慢项目。

### 16.2.2 什么时候成本会突然上升

- 模型频繁换代
- 输入输出尺寸不稳定
- 业务方不断增加新算子
- 板端 SDK 版本漂移
- 量产前临时换硬件

这些情况会让原本“看起来简单”的部署，迅速变成高风险项目。

**小结**
成本模型提醒的是，硬件只是显性成本，真正拖慢项目的常常是转换、适配、调试和维护。把隐性成本算进去，选型才不会被低估。
