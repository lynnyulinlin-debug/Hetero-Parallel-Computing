# 15.4 缓存一致性与内存模型（在异构系统中的含义）

这一节把“跨设备数据何时可见”说清楚，因为这是多设备协同里最容易被误判的正确性问题。

- 异构系统通常**无硬件级全局缓存一致性**，可见性靠显式同步保证。
- 统一内存/一致性互联（如 CXL）的演进方向。
- 对工程实现的直接结论：跨设备共享数据时必须显式设计同步点。

### 15.4.1 为什么不能默认“写完就可见”

在很多单机、多线程语境里，程序员容易形成一个习惯：写完某个内存位置，别的线程很快就能看到。  
但异构系统里，这个假设经常不成立，因为 CPU、GPU、NPU 之间往往没有统一的硬件缓存一致性。

因此，只要数据跨设备，就必须明确：

- 谁写
- 谁读
- 何时可读
- 通过什么同步机制可读

这也是为什么第14章里的队列、事件和阶段边界不是“工程装饰”，而是正确性的一部分。

**小结**
异构系统里的内存模型，核心不是记住更多术语，而是接受一个事实：跨设备数据默认不会自动可见。把同步点显式设计出来，正确性才可控。
