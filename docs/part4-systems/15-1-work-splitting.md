# 15.1 CPU 与协处理器的工作划分原则

- CPU：控制流、串行/分支密集、小数据低延迟任务。
- 协处理器：大规模数据并行、计算密集任务。
- 划分依据：算术强度、数据量、延迟敏感度。
- 大量分支、IO 或小批量操作优先放 CPU；稳定的大块数据并行优先放 GPU/NPU。

### 15.1.1 为什么要先划分，再优化

异构系统里最常见的错误，不是算子没写好，而是活分错了。  
如果一个阶段本来就包含大量分支、字符串处理或 I/O，却硬塞给 GPU/NPU，结果通常是：

- 计算单元利用率不高。
- 数据搬运和同步成本抬升。
- 调试复杂度远高于收益。

反过来，如果是稳定的大块数据并行任务，却留在 CPU 上做，也会浪费协处理器的能力。因此先划分、再优化，是异构系统里最基本的顺序。
