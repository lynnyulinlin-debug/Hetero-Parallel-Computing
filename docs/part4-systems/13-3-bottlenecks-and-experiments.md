# 13.3-13.4 瓶颈模式与实验对照

## 13.3 常见性能瓶颈模式

- 带宽受限：算术强度低，如向量加法。
- 计算受限：算力打满，如矩阵乘。
- 延迟受限：被同步或传输往返拖累，如频繁小批量 H2D。
- 图建议：Roofline 模型图，标出 `vec_add`、`reduce`、矩阵乘的位置。

## 13.4 实验对照

- `examples/ch09_vec_add`：验证带宽受限。
- `examples/ch09_reduce`：验证同步/原子开销。
- 第9.6节矩阵乘：验证计算受限。
- 结论：先判瓶颈类型，再选优化手段。

**动手实验**：先在 `examples/ch09_vec_add` 论证带宽受限，再用 `examples/ch09_reduce` 对比同步/原子的额外代价，最后把第9.6节矩阵乘作为计算受限对照。
