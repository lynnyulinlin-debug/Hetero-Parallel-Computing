# 第13章 异构系统的性能分析方法论

> 这一章把前面分散的优化技巧收敛成一套方法论：先测，再判因，再优化，再验证。

本章拆成三个部分，建议按顺序阅读：

1. [13.1 标准流程](13-1-standard-flow.md)
2. [13.2 工具链组合](13-2-toolchain.md)
3. [13.3-13.4 瓶颈模式与实验对照](13-3-bottlenecks-and-experiments.md)

## 先看什么

- 如果你想知道性能分析该怎么开始，先看 [13.1](13-1-standard-flow.md)。
- 如果你想知道该配哪些工具，先看 [13.2](13-2-toolchain.md)。
- 如果你想把方法论和例子连起来，直接看 [13.3-13.4](13-3-bottlenecks-and-experiments.md)。

## 本章要点

1. 性能优化必须走“基线→热点→假设→优化→验证”的闭环。
2. 异构系统要对齐多工具时间线，先判瓶颈类型再优化。
3. `vec_add`、`reduce`、矩阵乘构成本书最重要的三类对照实验。
