# 第13章 异构系统的性能分析方法论

> 本章把前面分散的优化技巧收敛成一套方法论：先测，再判因，再优化，再验证。

本章分成三个部分：

2. [13.2 工具链组合](13-2-toolchain.md)
3. [13.3-13.4 瓶颈模式与实验对照](13-3-bottlenecks-and-experiments.md)

## 先看什么

- [13.1](13-1-standard-flow.md)：性能分析的标准流程。
- [13.2](13-2-toolchain.md)：工具链如何配合。

## 本章要点

1. 性能优化必须走“基线→热点→假设→优化→验证”的闭环。
2. 异构系统要对齐多工具时间线，先判瓶颈类型再优化。
3. `vec_add`、`reduce`、矩阵乘是本书三类核心对照实验。
