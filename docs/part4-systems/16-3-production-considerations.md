# 16.3 从试点到量产的工程化考量

- 功耗、散热、稳定性、长期供货与固件/驱动维护都要算进去。
- 试点性能不等于量产性能。

### 16.3.1 试点和量产为什么不是一回事

试点阶段通常只证明一件事：在当前环境下，系统能跑到某个指标。  
但量产阶段要面对的是：

- 温度变化
- 供电波动
- 驱动/固件升级
- 业务负载变化
- 长期稳定运行

所以试点性能看起来很好，不代表量产能直接复制。  
工程上更稳妥的做法是先看稳定性，再看吞吐，再看成本。

### 16.3.2 量产最容易忽略的约束

- 散热空间不够
- 板卡供货不稳定
- 现场网络和电源环境差
- 维护团队不熟悉 SDK
- 后续模型迭代太频繁

如果这些条件不稳定，即使单点性能不错，也不一定适合直接量产。
