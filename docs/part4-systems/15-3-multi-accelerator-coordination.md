# 15.3 多协处理器协同

- 多 GPU（数据并行/模型并行）、GPU+NPU 混合。
- 设备间通信（如 NVLink、PCIe P2P）与负载均衡。
- 多设备协同的关键是让每个设备做最擅长的那部分。

### 15.3.1 多设备不是越多越好

很多系统一旦能用多设备，就会本能地想“把活全分出去”。这通常不是最优解。  
多设备协同是否有效，要看三件事：

1. 设备之间传输是否便宜。
2. 负载是否足够稳定。
3. 分工是否真的能减少总等待。

如果一个阶段很轻、通信却很重，多设备只会让复杂度上升。  
所以多设备协同的目标不是“把设备用满”，而是“把最适合的任务放到最适合的设备上”。
