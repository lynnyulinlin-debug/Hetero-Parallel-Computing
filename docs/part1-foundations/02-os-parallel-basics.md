# 第2章 操作系统层面的并行基础

> 这一章解决什么问题：建立并行执行的操作系统视角——进程/线程、同步、内存可见性，为后续 CPU 并行编程打底。

本章拆成四个部分，建议按顺序阅读：

1. [2.1 进程 vs 线程：并行的基本单位](02-1-process-vs-thread.md)
2. [2.2 线程同步原语：让队列安全运行](02-2-synchronization-primitives.md)
3. [2.3 原子操作与内存屏障：让数据可见](02-3-visibility-and-barriers.md)
4. [2.4-2.5 死锁、活锁与生产者-消费者](02-4-deadlock-and-producer-consumer.md)

## 先看什么

- 如果你想先搞清进程和线程的区别，先看 [2.1](02-1-process-vs-thread.md)。
- 如果你想理解同步原语怎么让队列安全运行，先看 [2.2](02-2-synchronization-primitives.md)。
- 如果你最关心“写了为什么别人看不见”，先看 [2.3](02-3-visibility-and-barriers.md)。
- 如果你想用一个任务队列串起全部概念，直接看 [2.4-2.5](02-4-deadlock-and-producer-consumer.md)。

## 本章要点

1. 进程隔离、线程共享，通信与切换开销决定设计选择。
2. 同步原语解决竞态，但引入开销与死锁风险。
3. 原子操作与内存屏障保证多核下的可见性与顺序。
4. 生产者-消费者是理解第2章所有概念的最小系统案例。
5. 第2章的目标不是背 API，而是把并行执行的底层机制看成一个可协调的任务系统。
