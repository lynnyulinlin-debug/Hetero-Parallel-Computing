# 8.2 协处理器的分类

GPU 和 NPU 的差别，不只是“一个通用、一个专用”，而是它们处理数据和执行指令的方式不同。

这一节的作用，是先把后面的两条主线分开。  
第9章要讲 GPU 编程和 profiler，第11章要讲 NPU 部署和模型转换；如果不先把两者的设计哲学区分清楚，后面的比较就很容易停留在“谁更快”的表层。

- **GPU**：通用并行计算，SIMT 架构，灵活但功耗高。
- **NPU**：AI 专用，脉动阵列/数据流，能效高但灵活性低。
- 二者设计哲学差异（详见第11.2节）。

把它们放到同一张图里看，最重要的是理解：

1. GPU 适合承担更广泛的并行计算，但对控制流和分支更敏感。
2. NPU 更适合重复、规则、矩阵化的 AI 计算，但对算子形态更挑剔。
3. 所谓“通用/专用”，本质上是在灵活性、能效和可编程性之间做不同权衡。

第8章先给出这层差异，后面的第9章和第11章才有共同的比较基准。

**小结**
GPU 和 NPU 的差别，不在名字，而在设计目标。前者偏通用并行，后者偏高能效推理；理解这点之后，后续选型就不会只盯着“谁更快”，而会先看“谁更适合这类工作负载”。
