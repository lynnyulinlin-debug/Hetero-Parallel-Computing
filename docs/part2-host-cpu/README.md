# 第二篇 主处理器篇 —— CPU并行编程

> 目标：先把 CPU 端的并行机制讲清，再把这些机制落到线程生命周期、OpenMP、SIMD 和异构系统的 Host 职责上。约60页。

这一篇的分工很明确：

- 第4章：线程创建、同步和线程池，任务如何被执行单元承载。
- 第5章：OpenMP，编译级并行如何把循环变成任务。
- 第6章：SIMD，单核内部的数据并行如何执行。
- 第7章：CPU 在异构系统中的职责，Host/Device 协同如何组织。
