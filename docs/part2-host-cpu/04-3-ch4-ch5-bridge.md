# 4.3 第4章和第5章的关系

第4章给你的是“底层控制权”，第5章给你的是“高层并行入口”。  
如果你理解了 pthread 里的任务切分和同步，就会更容易看懂 OpenMP 为什么能用一行 pragma 把循环并行化，也更容易在 OpenMP 出问题时追到线程层面。

---

**本章要点**
1. pthread 提供最底层的线程控制，灵活但易错。
2. 线程池摊薄线程生命周期开销，是高并发服务的基础。
3. 多数场景下 OpenMP 已足够，理解 pthread 有助于排查问题。
4. 第4章的重点不是记 API，而是理解“线程如何承载任务、同步如何管理生命周期”。

**动手实验**：把 `examples/ch09_vec_add` 的 OpenMP 版改写为 pthread 手动切分，对比代码复杂度。

> ⚡️ 入门读者本章仅需了解概念，可从第5章 OpenMP 上手。
