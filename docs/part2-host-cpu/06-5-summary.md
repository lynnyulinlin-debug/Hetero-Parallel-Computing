# 6.5 小结：SIMD 在 CPU 体系里的位置

SIMD 的价值，不是替代多线程，而是把单线程内部的吞吐再往上提一层。  
在工程上，常见顺序通常是：

1. 先把任务并行化。
2. 再让单核内部尽量向量化。
3. 最后在必要时才手写 intrinsics。

---

**本章要点**
1. SIMD 是核内数据并行，与多线程可叠加。
2. 优先依赖编译器自动向量化，并用报告验证效果。
3. intrinsics 是最后手段，可控但可移植性差。
4. SIMD 的真正价值，是让 CPU 在不增加线程的情况下继续提升单核吞吐。

**动手实验**：用 `-fopt-info-vec` 检查向量加法是否被自动向量化；关闭 `-O3` 对比性能。
