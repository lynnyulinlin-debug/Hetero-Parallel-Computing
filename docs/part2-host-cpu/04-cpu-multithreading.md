## 统一案例

第4章围绕“一个固定的任务队列如何被多个工作线程消费”来讲：

- 主线程不断投递任务。
- 工作线程从队列中取任务并执行。
- 队列需要保护，线程需要生命周期管理。
- 任务过多时，线程池比“临时创建线程”更稳定。

这个案例把第2章的同步和可见性概念，落成可运行的 CPU 并发结构。第5章会把同样的问题换成 OpenMP 的 pragma 与调度策略，第7章则会把它扩展到 Host 与协处理器之间的任务交接。

## 本章要点

1. pthread 提供最底层的线程控制，灵活但易错。
2. 线程池摊薄线程生命周期开销，是高并发服务的基础。
3. 多数场景下 OpenMP 已足够，理解 pthread 有助于排查问题。
4. 第4章的重点是“线程如何承载任务、同步如何管理生命周期”。
