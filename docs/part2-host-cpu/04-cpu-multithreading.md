# 第4章 CPU多线程编程

> 这一章解决什么问题：掌握最底层的线程编程接口（pthread），理解 OpenMP 等高层抽象底下到底发生了什么。

本章拆成三个部分，建议按顺序阅读：

1. [4.1 POSIX 线程（pthread）入门](04-1-pthread-basics.md)
2. [4.2 线程池设计与实现](04-2-thread-pool.md)
3. [4.3 第4章与第5章的关系](04-3-ch4-ch5-bridge.md)

## 先看什么

- 如果你想先理解线程是怎么被创建和回收的，先看 [4.1](04-1-pthread-basics.md)。
- 如果你想知道线程池为什么是工程方案，先看 [4.2](04-2-thread-pool.md)。
- 如果你想把第4章和第5章连起来，直接看 [4.3](04-3-ch4-ch5-bridge.md)。

## 本章要点

1. pthread 提供最底层的线程控制，灵活但易错。
2. 线程池摊薄线程生命周期开销，是高并发服务的基础。
3. 多数场景下 OpenMP 已足够，理解 pthread 有助于排查问题。
4. 第4章的重点不是记 API，而是理解“线程如何承载任务、同步如何管理生命周期”。
