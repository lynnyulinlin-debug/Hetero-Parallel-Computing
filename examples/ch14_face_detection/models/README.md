# 模型说明

当前目录用于存放真实的人脸检测模型文件或下载脚本。

最小可运行骨架阶段，这里不强制放入模型文件；后续接入真实模型时再补充：

- 权重文件
- 导出脚本
- 后端转换说明

真实输入样例请参考 [video_source_example.md](video_source_example.md)。
如果需要摄像头或混合来源写法，再看 [camera_source_example.md](camera_source_example.md)。
如果需要文件 / 摄像头 / RTSP 混合写法，再看 [stream_source_example.md](stream_source_example.md)。
真实输入接入流程请看 [input_integration_guide.md](input_integration_guide.md)。
